# Testing

- `npm run test`: shared-domain and web tests.
- `npm run typecheck`: strict TypeScript checks.
- `npm run lint`: ESLint.
- `npm run build`: production Next.js build.
- `npm run contract:test`: Rust contract tests.

Only commands explicitly reported as passed in a completion report should be treated as verified. No live Stellar testnet test has been performed in this repository.
